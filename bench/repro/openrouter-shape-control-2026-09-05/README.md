# Standalone formatting and request-shape diagnostic

This ten-call control uses the **first already-exposed v2 development case**.
It is not a native optimizer experiment, model ranking, reliability estimate,
or permission to promote the failed workflow into a larger study.

Two literal-copy controls, one per model, ask for the arbitrary string
`D02|D06|D17` under a minimal copying instruction. The other eight calls form a
factorial: Sonnet/Haiku × single/multiple user messages × full/stage-local
question. All selection cells retain the frozen filter system instruction and
final-user output grammar. Single-user packing joins the same document and
question contents with double newlines; the local question omits the irrelevant
requisition and approval policy. These are diagnostic interventions, not changes
to the earlier frozen experiments. The two copy controls are not factorial cells.

All ten exact payloads, ordering, source hashes, public case, endpoint metadata,
and scoring contract are frozen before inference. Each uses 512 output tokens,
temperature zero, the pinned Anthropic provider, no provider fallback, and no
reasoning override. There are no dependent suffixes, invalid upstream states,
native observations, or heldout questions. Only the evaluator computes the
correct document selection from public tenant records. Raw outputs are never
trimmed, extracted, reordered, or otherwise repaired.

The hard stage cap is **$0.50** inside the original shared **$50** ledger,
including every historical and new retained allowance. There is **no automatic
retry**, including across invocations: any failed attempt stops this stage and
keeps its full budget commitment. The filtered requests from the previous pilots
are never retried here.

Saved result prefixes must exactly match durable request fingerprints, provider
responses, endpoint attribution, billing, and unique generation IDs before any
new call. A crash after provider accounting but before artifact persistence can
recover the existing result without redispatch. A shorter replay cannot overwrite
a longer saved prefix. Partial runs report accounting but no comparisons; only
all ten validly attributed completions produce the strict-format/exact-match
table. Malformed formatting remains a scored failure rather than a transport
failure. Ordinary response text, reported reasoning tokens, and finish reasons
are recorded separately; missing telemetry is not converted to zero.

Use `python -m bench.openrouter_shape_control prepare` with explicit `--previous`
v2 manifest, `--fixture`, `--env-file`, original `--ledger`, and `--output`.
After independent review, `run` requires the externally recorded
`--manifest-sha256`; `--max-calls` may request a nondecreasing prefix.
No preparation or provider calls were made during implementation.

One sample per cell can help locate instruction/role-shape sensitivity, but
cannot establish general model behavior. Even if single-user packing succeeds,
it does not preserve the current message-level ContextCompress mechanism and
cannot be silently substituted into the native study. A successful diagnostic
would justify a separate, prospectively frozen multi-case feasibility screen.
